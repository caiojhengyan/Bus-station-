玩法教學

1. 設定題庫

  • 「開始」頁勾選縣市（可多選）。
  • 輸入路線後按「加入」，多條用逗號分隔；旁邊打勾表示出題。
  • 路線可省略「路」：19 = 19路，19A = 19路A。
  • 不標主/副時，主線與副線一起出題。
  • 範圍：6700~6710 會從這些路線中出題。
  • 沒加入任何路線時，從所選縣市全部路線出題。

2. 填空題（預設）

  • 地圖顯示整條路線，下方直線上每個點是一站。
  • 在輸入框打任一站名，打對自動填到對應位置，不用照順序。
  • 點直線上的點，地圖會標出該站位置。
  • 「顯示答案」看全部站名，「換一題」換路線。
  • 設置可開啟「去返程視為同一題」。

3. 單站問答

  • 設置切換模式。地圖標出一站，輸入站名後按「送出」，不限題數。

4. 設置

  • 需先填 TDX Client ID / Secret。
  • 可換顏色、地圖（OpenStreetMap／Google 地圖）。
